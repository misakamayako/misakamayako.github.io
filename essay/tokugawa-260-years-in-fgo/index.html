印笼里的两百六十年

2026/09/29misakamayako
随笔FGO历史

查 FGO《德川回天迷宫 大奥》资料的时候，我原本以为那些技能名是倒幕运动的事件清单。一路看下来，发现自己想窄了。

它们覆盖的其实是整个江户时代——从德川家康受封征夷大将军、建立江户幕府，中间经过历代将军的政治改革和地方上的民变，一直到幕末的倒幕运动和幕府终结，前后大约两百六十年。

而且它并不是把历史事件排个队就完事。技能是跟着德川将军的历史顺序逐步强化的：每拿到一位将军的印笼，技能就升一级，最后汇聚到幕府的建立和终结这两端。

这跟活动主题「德川回天」咬得很紧。玩家在游戏里一点点获得的力量，实际上就是德川幕府整个历史的缩影。

下面按历史背景捋一遍。

一、幕府前期：德川统治的建立与巩固

技能名称历史背景与倒幕的关系
江户开府1603 年，德川家康受封征夷大将军，建立江户幕府。幕府的起点
武家诸法度幕府规范大名及武士行为的基本法令，维护幕藩体制。维护幕府统治
生类怜悯令德川纲吉时期颁布的保护生物相关法令，尤其以保护犬类闻名。与倒幕无直接关系
狗将军德川纲吉的绰号，源于其保护犬类的政策。将军个人称号
天和之治德川纲吉时期的政治统治与政策。幕府治理的一部分
明历大火1657 年江户发生的大火，烧毁江户城及大量市区，之后推动城市重建。重大灾害
绘岛生岛事件1714 年，大奥女官绘岛与歌舞伎演员生岛新五郎的丑闻及其引发的惩处事件。幕府内部政治事件

其中比较有趣的是生类怜悯令与狗将军：FGO 将政策和将军绰号分别设置为技能，实际上是在表现德川纲吉的统治特色——不只是「他做了什么事」，还包括「他因此被记住成什么样的人」。

二、幕府中期：改革、民变与政治矛盾

技能名称历史背景与倒幕的关系
正德之治德川家宣、侧用人新井白石主导的政治改革，涉及财政、外交及幕府治理。幕府内部改革
进言箱德川吉宗时期设置的目安箱，允许民众向幕府提出意见与建议。改善幕府治理
宽政改革松平定信于 18 世纪末推行的改革，强调财政整顿、节俭与社会秩序。幕府自救
郡上一揆1750 年代美浓国郡上藩发生的农民抗争，起因涉及年贡征收制度改革。地方民变
天保改革1841 年起水野忠邦推行的幕府改革，涉及财政、物价、城市及社会管制。幕府自救
捣毁（打ちこわし）江户时代城市民众因米价上涨等原因冲击商铺、粮商的集体行动。社会动荡

这里有一个值得注意的细节：郡上一揆与捣毁并不是倒幕运动本身。它们反映的是江户幕府统治过程中不断出现的社会矛盾——尤其是农民抗争和城市暴动，说明幕府的统治并非始终稳定。

不过，这些事件也不能简单理解为民众已经具有推翻德川幕府的政治目标。社会矛盾是持续的，推翻幕府是后来的事，两者之间不能直接画等号。

三、幕末：倒幕运动真正开始的历史背景

技能名称历史背景与倒幕的关系
日美和亲条约1854 年签订，结束日本长期的闭关状态，开放下田、箱馆等港口。幕末外交转折
安政大狱1858—1859 年井伊直弼镇压反对派及尊王攘夷人士的政治事件。加剧幕府与反对派冲突
大政奉还1867 年德川庆喜将政权奉还朝廷。幕府终结的关键步骤
无血开城1868 年胜海舟与西乡隆盛协商，使江户城和平交接。避免江户陷入大规模战火
王政复古大号令1868 年 1 月 3 日发布，宣布废除幕府及传统朝廷部分官制，建立新的政治体制。倒幕派建立新政权的关键事件

这里最值得区分的是大政奉还与王政复古大号令。

大政奉还与王政复古：看似相似，实际是两条不同的政治路线

德川庆喜的路线是大政奉还（1867）：将政权交还朝廷，但希望通过新的政治体制保留德川家在国家政务中的重要地位。

倒幕派的路线是王政复古大号令（1868）：废除幕府及相关旧制度，建立以天皇为中心的新政府，排除德川家原有的政治权力。

两者之间的政治冲突最终发展为戊辰战争。

所以，德川庆喜主动交还政权，并不意味着倒幕派已经实现了全部政治目标。这两件事被放在同一个历史段落里，但政治含义相差很远。

四、FGO 的技能设计有什么特别之处？

我觉得最有意思的地方，是它将技能设计成了三组不同的历史叙事。

第一组：幕府的权威与统治

生类怜悯令 → 绘岛生岛事件 → 正德之治 → 安政大狱 → 江户开府 → 大政奉还

从将军个人政策、幕府内部政治，到幕府建立与最终交还政权。

第二组：幕府的应对与危机

狗将军 → 日美和亲条约 → 明历大火 → 进言箱 → 捣毁 → 无血开城

从纲吉时期的政治特色，经过外交冲击、灾害、改革与社会动荡，最终走向江户城的和平交接。

第三组：幕府的治理与社会基础

天和之治 → 郡上一揆 → 武家诸法度 → 天保改革 → 宽政改革 → 王政复古大号令

从幕府治理制度、地方社会冲突，到一系列改革，最后以旧体制的终结收尾。

需要说明的是，以上是我按照技能强化顺序整理出的主题解读，不代表游戏官方明确声明过这三条历史寓意。技能的实际升级顺序见活动资料。

还有一个容易忽略的细节

FGO 将「江户开府」与「大政奉还」设置在同一技能的强化链上。

这相当于把德川幕府的两个历史节点——建立与终结——塞进了同一条技能成长线。而「无血开城」与「王政复古大号令」则分别出现在另外两条技能线上。

如果从活动剧情的角度理解，玩家并非单纯在收集德川历代将军的力量，而是在逐步获得整个德川幕府的历史。

这也解释了为什么活动最终会涉及德川家康、德川庆喜，以及日本历史上幕府政治的终结。

一点题外话

我一开始之所以会误判，大概是因为「倒幕」这个词太响，盖住了前面那两百多年。

但回头看，这个活动如果把技能名全做成幕末事件，反而不好玩了——幕末只有十几年，事件密度高但跨度短，做成技能链会很挤。而把整个江户时代铺开，从 1603 到 1868，才能撑起「一点点收集历代将军」这种结构。

历史在这里不是背景板，而是玩法本身。玩家升级的过程，就是德川幕府从建立走到终结的过程。这种把机制和主题绑在一起的做法，比单纯在剧情里讲一遍历史要聪明。
